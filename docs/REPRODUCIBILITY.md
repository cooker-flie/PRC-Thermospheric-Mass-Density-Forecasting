# 实验配置与科学边界

- 主权重：PatchTST，64 维，4 个注意力头，2 层编码器，历史/预测长度均为 288。
- 架构对比：按历史实验记录使用 128 维；不可为了文本一致而把该实验改写成 64 维。
- 原训练入口保留 LSTM、Transformer、Informer、TFT、PatchTST，以及既有 Autoformer 实现。
- 这些是项目中的实际实现，并非承诺与每个外部论文的官方实现完全等价。
- 数据先做日志密度变换和归一化。PatchTST 不使用未来显式条件输入，但残差重建使用目标时段的经验模型基线。
- 所以历史回溯评价不自动等于起报时全部信息可得的实时预报。
- 推理的 --persist_baseline 只额外生成持久化基线比较，不会自动替换 PRC 重建中的经验基线。
- 原数据填补、时间窗口重叠和划分策略保持原样，未借整理项目悄悄修订算法。
- configs 中的演示配置只验证流程；完整论文训练需补齐多年数据和真实运行配置。
- PyTorch 权重采用 pickle 相关格式，入口使用 weights_only=False，仅加载可信来源文件。
- 跨机器浮点误差和随机性可能导致指标变化；要求精确复现时归档依赖版本、硬件及运行命令。
